Multi-Library Enterprise Edition

HS Library — Enterprise Multi-Tenant Platform

Designed as a commercial-grade, multi-tenant SaaS application for academic institutions, providing complete cryptographic isolation, ACID transaction guarantees, and editorial UX.

Strict Data Isolation

Every database query is strictly scoped to the authenticated librarian's library_id. Cross-tenant tampering is cryptographically blocked at the API layer.

Bcrypt Authentication

Passwords salted and hashed using bcrypt. Access tokens signed via HMAC-SHA256 JWT, with session expiry and rate-limiting protections.

Multi-Tenant Architecture

Support for unlimited independent campus libraries, each with their own books, students, circulation desks, and audit ledgers.

Dual-Engine Reliability

Compatible with MySQL 8+ on Workbench and auto-failover to persistent zero-config Relational SQLite for uninterrupted portable operation.

Technical Specifications

Backend Engine Node.js + Express.js REST API
Security & Auth Bcrypt Hashing + JWT Bearer Auth
Data Architecture Multi-Tenant Foreign Key Scoping
Relational Stores MySQL 8.0 / Persistent InnoDB
Design System Deep Indigo / Violet Editorial SaaS

TQM Project Q09: Architectural Quality Controls

Implemented & Verified

1. Centralized Exception Handling

Global Express middleware traps synchronous and async failures. Normalizes error payloads to standardized JSON schema with status codes, preventing raw stack traces and internal SQL leaks.

X-Request-Id Tracing • 0 Information Leaks

2. Strict Input Validation & Sanitization

Pure validation pipeline validates ISBN-10/13 checksum formats, student enrollment codes, email structures, 14-day default circulation periods, and HTML sanitization preventing stored XSS.

HTML Entity Escaping • Type Validation

3. Automated Regression Test Suite

47 automated unit & integration tests runnable natively via npm test. Validates auth tokens, multi-tenant library isolation, book inventory mutations, circulation lifecycle, and defect operations.

47/47 Passing (100%) • 0 Dependencies

Dual file and console logger rotating automatically at 5MB with 3 rolling backups. Passwords, auth tokens, session secrets, and database credentials automatically redacted before emission.
